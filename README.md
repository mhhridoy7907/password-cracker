# 🔐 Password-Cracker

A **cyber security demo project** that visualizes password strength, entropy calculation, and brute-force attack simulation using pure HTML, CSS, and JavaScript.

---

## ⚡ Features

- 🔑 Real-time password strength checker  
- 📊 Entropy calculation (bits)  
- 🧠 Crack time estimation  
- 💥 Brute-force attack animation simulation  
- 🎮 Hacker-style console output  
- 🎨 Cyber neon UI design  
- 🔄 Random password generator

## 🧪 How It Works

- User enters a password  
- System calculates:
  - Character set size  
  - Entropy (strength level)  
- UI shows:
  - Strength meter  
  - Crack probability  
- On "OK" click:
  - Simulated brute-force attack starts  
  - Random character attempts displayed  
  - Progress bar increases  
- Final result shows:
  - Password cracked OR strong password protected
